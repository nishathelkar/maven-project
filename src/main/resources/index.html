01 — INTRODUCTION

WHAT IS DEVOPS?

DevOps is a combination of development and operations practices that helps teams work together throughout the software lifecycle.

Instead of developers and operations teams working separately, DevOps encourages collaboration, automation, continuous integration and continuous delivery.

The goal is to deliver software faster, improve reliability and continuously improve the application using feedback and monitoring.

02 — VERSION CONTROL

WHAT IS GIT?

● git

Git — Version Control System

Git is a distributed version control system used to track changes in source code.

Developers can create branches, make changes, commit their work and merge changes together.

$ git init

$ git add .

$ git commit -m "My project"

$ git branch

$ git merge

03 — COLLABORATION

WHAT IS GITHUB?

GitHub — Code Collaboration Platform

GitHub is a platform where developers can store, share and collaborate on software projects using Git repositories.

Teams can use repositories, branches, pull requests, code reviews and automated workflows to collaborate on projects.
